Compact & Convenient

Automatic Folding

One of the HW009's main features is its automatic folding system. Folding and unfolding is controlled using the buttons on the rear of the scooter, allowing it to reduce into a compact package for storage and transport.

01

02

04
Folded
No manual folding mechanism to wrestle with.

Switch the scooter off and fold the backrest down, then use the red button on the rear to begin the automatic folding cycle. The green rear button operates the automatic unfolding cycle. The scooter stops automatically when the cycle is complete.

Simple To Use

Getting Going

Straightforward everyday controls make the scooter easy to prepare, drive and store.

01

Unfold

Position the scooter securely and use the green control on the rear to start the automatic unfolding cycle.

02

Switch On

Insert the key and switch the scooter on. The tiller provides the battery indicator, speed control, horn and lighting controls.

03

Ride

Select a suitable maximum speed and use the drive control to move. Releasing the control allows the electromagnetic braking system to bring the scooter to a stop.

Good to know

This is a compact Class 2 mobility scooter intended primarily for indoor use and suitable level outdoor surfaces. As with any mobility scooter, the manufacturer's operating and safety guidance should be followed, particularly regarding gradients, uneven ground and poor weather.
