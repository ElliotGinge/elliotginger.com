Compact & Convenient

Automatic Folding

Designed to fold down into a compact package for easier storage and transport. Folding and unfolding is controlled using the buttons on the rear of the scooter.

From scooter to compact storage.

The seat and tiller fold down automatically, allowing the scooter to take up considerably less room when it is not in use.

Once folded, it can be stored upright using its transport wheels — useful around the home or when travelling.

Simple To Use

Getting Going

The HW009 uses straightforward controls for everyday operation, with speed adjustment, battery indication, lighting and horn controls on the tiller.

01

Unfold

Use the rear unfold control and allow the scooter to complete its automatic unfolding cycle.

02

Switch On

Insert the key, switch the scooter on and check the battery indicator before setting off.

03

Ride

Select a suitable speed using the tiller control and use the drive lever to move. Releasing the control engages the electromagnetic brake.
